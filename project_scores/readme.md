# 学生成绩分析

**数据**：scores_raw.csv（32 行，自造），含 4 个缺失值、2 行重复
**做法**：
1. merge 班级表（how='inner'）
2. drop_duplicates(subset=['学号']) 去重：32 → 30
3. dropna(subset=[三科]) 删缺失：30 → 26
4. groupby('班级') 算三科均分，出柱状图 + 箱线图

**结论**：
- 一班语文、英语最好；二班数学最高（84.00）；三班三科均垫底
- 缺失值为**缺考**，不代表 0 分，故按缺失删除。若填 0，一班/三班数学均分虚低约 8 分

**运行**：`py main.py` → 生成 chart1.png / chart2.png
